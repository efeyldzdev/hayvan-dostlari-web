# hayvan-dostlari-web
# Hayvan Dostları Web Sitesi

Bu proje, sokak hayvanları için farkındalık yaratmak ve destek sağlamak amacıyla geliştirilmiştir.

## 🌟 Özellikler

- Tema değiştirici (Mavi / Pembe / Beyaz / Siyah / Uzay)
- Responsive tasarım
- Sahiplendirme ve bağış bölümleri
- Etkinlik galerisi
- İletişim formu ve sosyal medya bağlantıları
- Smooth scroll ve animasyonlu geçişler

## 🛠️ Kullanılan Teknolojiler

- HTML5, CSS3, JavaScript
- FontAwesome
- Google Fonts
